OpenCode Cheat Sheet
OpenCode v2 — the open source AI coding agent for your terminal. Talk to your codebase, run tools, edit files, and ship — with any model, any provider, fully local-first.

Get Started
opencodeStart the TUI in the current directory
opencode /pathStart in a specific project
opencode run "…"One-shot, non-interactive prompt
opencode auth loginAdd a provider & API key

brew install anomalyco/tap/opencode-v2

Leader Key Ctrl + X, then…

Custom Commands

Drop a Markdown file in .opencode/commands/ (project) or ~/.config/opencode/commands/ (global). File name = command name.

--- .opencode/commands/test.md ---
description: Run tests with coverage
agent: build
model: anthropic/claude-sonnet-5-5
---
Run the suite. Focus on failures: $ARGUMENTS
Recent commits: !`git log --oneline -10`

Placeholders: $ARGUMENTS, $1, $2… · !`cmd` injects output · @file injects a file.

Agents
build · primaryDefault. All tools, may ask questions
plan · primaryEdits denied except ~/.opencode/plan
general · subFull tools; no questions or subagents
explore · subFast search; no edits or subagents

Shift+Tab cycles agents. Invoke a subagent with @name. Navigate child sessions with ↓ to enter, ←/→ to cycle, ↑ to return.

Configuration
opencode.json(c)Project & server settings
cli.jsonCLI/TUI settings — global only
~/.config/opencode/Agents, commands, plugins
{
  "$schema": "https://opencode.ai/v2/cli.json",
  "theme": { "name": "tokyonight", "mode": "system" },
  "tabs": { "mode": "auto", "layout": "horizontal" },
  "keybinds": { "leader": "ctrl+x" },
  "leader": { "timeout": 2000 }
}

Project settings live in opencode.json(c); cli.json has no project-local file and reloads live.

Permissions

In opencode.json(c). Ordered rules; the last match wins — each is action + resource + effect.

"permissions": [
  { "action": "shell", "resource": "*", "effect": "ask" },
  { "action": "shell", "resource": "git *", "effect": "allow" },
  { "action": "shell", "resource": "rm *", "effect": "deny" }
]
Actionsread edit glob grep shell subagent skill webfetch websearch external_directory question execute
DefaultsBase policy allows; .env reads ask; no match → ask
Approvalsonce · always (saves a project rule) · reject

Agent rules append via agents.<id>.permissions. opencode run --auto accepts whatever is not denied.
